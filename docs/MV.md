## 关联 MV 与桌面壁纸

在「设置 → 终端偏好」中开启「自动播放关联 MV」。独立窗口会读取平台提供的关联 MV；没有关联时默认匹配搜索首项，无结果或加载失败时显示提示，音乐继续播放。

视频始终静音，跟随主播放器切歌、暂停、恢复和跳转，不改变音频音质或播放队列。独立窗口支持视频版本选择、透明度、画面偏移、全屏、置顶和鼠标点击穿透。独立 MV 窗口支持 Linux、Windows 和 macOS；桌面壁纸目前仅在 Windows 提供，支持显示器选择、桌面进度控制和音乐频谱波浪。

搜索结果不保证与当前歌曲完全一致，选择前请核对标题与歌手。视频可用性取决于平台收录、地区和账号权限。


窗口底部可选择视频版本和 20%–100% 的透明度，支持 F11 全屏、Esc 退出全屏。独立窗口可直接拖到副屏。

优先播放为歌曲记住的手动版本，其次播放歌曲明确关联的 MV；没有明确关联时自动选择搜索首项。版本列表提供按歌名筛选的 MV 搜索结果（包括现场、翻唱等），标明来源与歌手，手动选择后按歌曲记住。

播放器底栏歌词按钮旁的「MV」可直接调出独立播放窗口。窗口图钉用于置顶；「锁定」会使视频和其他控件穿透鼠标点击，仅原位置的「解锁」按钮可操作，再次点击即可恢复。

全屏时鼠标静止约 2.5 秒后自动隐藏上下控制栏，移动鼠标即可恢复；展开菜单或拖动滑块时保持显示。

MV 与音频存在片头或剪辑时间差时，可用「画面偏移」以 0.5 秒为单位校准；正值让画面提前。偏移按 MV 保存，透明度也会记住；拔下显示器后窗口自动回到可用屏幕。关闭 MV 窗口会同时关闭自动播放，可在设置中重新开启。

Windows 下可在 MV 窗口点击「桌面壁纸」，再选择「壁纸显示器」。视频嵌入桌面图标下方，跟随音乐暂停、跳转与切歌，模式和显示器选择会记住；显示器断开时回到主屏。桌面壁纸目前仅在 Windows 提供，由 `Qt/src/PlatformFeatures.h` 统一声明能力。

壁纸底部常驻金色发光进度条、播放／暂停和「退出壁纸」，控件直接叠加在 MV 画面内，并带弱阴影。壁纸模式下关闭 MV 设置窗口不会停止桌面播放，可从桌面控制条的「设置」重新打开。

进度条上的波浪来自主播放器实际解码音频的频谱，暂停后收平；拖动进度会调整歌曲与 MV 的同步位置。「退出壁纸」只关闭 MV 自动播放，音乐继续。点击「返回窗口」可恢复独立窗口播放；没有可用 MV 或视频加载失败时保留原桌面背景。壁纸模式不会修改系统保存的壁纸文件，退出应用后恢复原背景。
